### ผลงานโปรเจกต์ (Featured Projects)

#### 1. Unimarket - แพลตฟอร์มซื้อขายสำหรับนักศึกษา
เว็บแอปพลิเคชันตลาดกลางซื้อขายสินค้า C2C สำหรับนักศึกษามหาวิทยาลัย เพื่อให้สามารถซื้อขายได้อย่างปลอดภัยภายในประชาคมมหาวิทยาลัย

* **Tech Stack:** `Django` | `Node.js` | `PostgreSQL` | `TailwindCSS` | `HTML5`
* **ฟีเจอร์สำคัญ:**
  * พัฒนาระบบยืนยันตัวตนจำกัดโดเมนด้วย OAuth2 (Google Social Login) โดยอนุญาตเฉพาะอีเมลมหาวิทยาลัย (`@ubu.ac.th`)
  * พัฒนา Full CRUD API สำหรับการจัดการสินค้า, ระบบค้นหาแบบยืดหยุ่น (Live Search), การแยกหมวดหมู่ และระบบสินค้าที่ชอบ (Wishlist)
  * ออกแบบโครงสร้างฐานข้อมูลเชิงสัมพันธ์ (Relational Data Model) สำหรับสินค้า, รีวิวผู้ใช้, รายการธุรกรรม และหมวดหมู่สินค้า

#### 2. UBU Event Management Platform - แพลตฟอร์มบริหารจัดการกิจกรรม
แพลตฟอร์มบริหารจัดการกิจกรรมศูนย์กลางภายในมหาวิทยาลัย รองรับการลงทะเบียนเข้าร่วมกิจกรรม ตารางเวลา และข่าวประกาศแบบเรียลไทม์

* **Tech Stack:** `React` | `Firebase Auth` | `Cloud Firestore` | `Firebase Hosting` | `TailwindCSS`
* **ฟีเจอร์สำคัญ:**
  * เชื่อมต่อ Firebase Auth และ Cloud Firestore จัดการบทบาทผู้ใช้งานและซิงค์ข้อมูลผู้เข้าร่วมงานแบบเรียลไทม์
  * ออกแบบ UI ให้รองรับการแสดงผลทุกขนาดหน้าจอ (Mobile-responsive) และทำการ Deploy บน Firebase Hosting
